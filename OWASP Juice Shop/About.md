# Project Overview
During the project, OWASP Juice Shop was deployed on several machines to test it for various web application vulnerabilities. 

### Objectives 
- Identify and Explore OWASP Juice Shop Application
- Perform Vulnerability Analysis
- Perform SAST and DAST on the application
- Analyse findings 
### Outcome
Varios vulnerabilites were found and exploited within the application,mittigations were recommended for each. SAST and DAST were performed on the code of the application to further evaluate its' security flaws. 
Results were then linked to the MITRE ATT&CK® Framework.
