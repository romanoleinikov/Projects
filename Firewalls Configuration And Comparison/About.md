# Project Overview
Built a virtualised testbed with a VM-Server in a private subnet and a VM-Public in a public subnet, with a firewall between them. Tested rule enforcement and logging using Nmap, DirBuster and Metasploit (reconnaissance and denial-of-service), then compared the two firewalls in a written report. 
Presentation is added with summary of comparison and tests. 
### Objectives
- Configure two open-source firewalls
- Test their performance and functionality
- Highlight strong and weak sides of each firewall
### Outcome
Both firewalls were apropriately tested, including simulating DOS attack. Results and overall functionality of both firewalls were compared.
